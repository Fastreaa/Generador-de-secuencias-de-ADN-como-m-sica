# Generador-de-secuencias-de-ADN-como-musica
El ADN tiene 4 letras. Las células las leen de 3 en 3, cada trío es una instrucción biológica. Mapeé esas instrucciones a notas. Esto no es música compuesta: es el gen de la insulina, tocado nucleótido por nucleótido con una raspberry pico pi y micropython
